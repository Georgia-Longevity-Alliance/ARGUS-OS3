# ARGUS-OS3 — Ablation Platform

ARGUS-OS3 is the **ablation-capable evolution** of the ARGUS-LP_OS platform. Where v1.0 observes and v2.0 perturbs genetically, OS3 intervenes physically — femtosecond laser ablation, micromanipulation, and microinjection.

**Budget:** $40,600 | **Status:** 🟡 Concept phase | **Grant:** EIC Pathfinder WP2 (October 2026)

## What it adds to v1.0

| Component | Purpose | $ |
|-----------|---------|--:|
| Micromanipulator (FOSH-adapted, 3-axis) | Sister separation, cell positioning | 1,208 |
| Pneumatic microinjector | Apoptosis factors, dyes, siRNA | incl. above |
| Femtosecond laser NIR 800 nm | Whole-cell ablation | 8,000 |
| Cooled sCMOS (ZWO ASI183MM Pro) | High-sensitivity imaging | 1,800 |
| Mac M4 Pro | AI agent (local LLM) | 2,200 |
| 2× Camera NoIR + 3× IR LED | Multi-camera night vision | 70 |
| UV-C sterilisation | Glove-box decontamination | 500 |
| Internal storage | Shelves, drawers, racks | 300 |
| Laser safety | OD6+ goggles, interlock, beam dump | 500 |

## Three Intervention Modes

| Mode | Tool | Purpose |
|:----:|------|---------|
| Sister separation | Micromanipulator + glass capillary 1-2 µm | Physical cell separation |
| Microinjection | Pneumatic injector | Apoptosis factors, dyes, siRNA |
| Laser ablation | fs NIR 800 nm | Whole-cell ablation |

## Ablation Arms

| Arm | Action | Track |
|:---:|--------|-------|
| A | Ablate cell with MATURE mother | Surviving sister fate |
| B | Ablate cell with IMMATURE daughter | Surviving sister fate |
| Sham | Laser at intercellular space | Both sisters |
| Control | No manipulation | Natural comparison |
