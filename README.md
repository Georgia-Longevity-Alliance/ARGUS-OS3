# README — ARGUS-OS3

ARGUS-OS3: прогениторные карты на основе spindle orientation pedigrees центриолей.

**Зависит от:** ARGUS-OS2 (доказательство конвергенции).
**Принцип:** граф где узлы = клеточные судьбы, рёбра = spindle orientation pedigree (∥/⟂), конвергенции = классы эквивалентности.

Старая концепция (fs- + ы) заменена на информационный подход.
