# README — ARGUS-OS3

ARGUS-OS3: прогениторные карты на основе траекторий центриолей.

**Зависит от:** ARGUS-OS2 (доказательство конвергенции).
**Принцип:** граф где узлы = клеточные судьбы, рёбра = траектории (∥/⟂), конвергенции = классы эквивалентности.

Старая концепция (fs-лазер + манипуляторы) заменена на информационный подход.
